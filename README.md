# Password Generator

This project is a password generator developed with Angular. It allows you to create random and secure passwords based on criteria specified by the user.
This project have been made with a Udemy Course (Stephen Grider).

## Live app

You can try the app following this link : https://pw-generator-brown.vercel.app/

## Features

* **Customizable length:** The user can choose the length of the password to generate.

* **Character selection:** The user can include or exclude different types of characters:

    * Letters

    * Numbers

    * Special characters

* **Password preview:** The generated password(s) are displayed to the user.

## Technologies used

* Angular

* TypeScript

* HTML

* CSS

## Installation

1.  Clone this repository:

    `git clone https://github.com/axellelanca/pw-generator.git`

2.  Install dependencies with:

    `npm install`

3.  Start the application with:

    `ng serve`

4.  Open your browser at:

    `http://localhost:4200/`

## Usage

1.  Open the password generator page in your browser.

2.  Set the options according to your preferences:

    * Password length

    * Types of characters to include

    * Number of passwords to generate

    * Exclude ambiguous characters

3.  Click the "Generate" button.

4.  The generated password(s) will be displayed on the page.

## Code structure

The project is an Angular application and follows the standard structure of an Angular project. The main components and services are located in the `src/app` folder.

* `src/app/app.component.ts`: Main application component.

* `src/app/...`: Other components and services.

* `angular.json`: Angular project configuration.
